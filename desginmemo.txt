How did recursive insertion work?
For this recursive insertion, it starts as the root of the tree and and
confirmed if the current node was the manager. If true, the new employee would 
be added to either left or right side. If false, it would keep looking through
the tree until it found the manager.

When might trees be preferable to other data structures in real-world systems?
Tree are preferable to other data structures when information needs to be organized 
in a way where there is a main source with multiple subtopics with it’s own subtopics. 
Visually, this type of stored information for my perspective trickles down in what more looks 
like roots than branches. This could be things like files on a computer and/or information for 
data analyzers.
